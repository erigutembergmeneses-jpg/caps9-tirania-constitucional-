# Capítulo 9 — Alerta Precoce e Monitoramento da Preservação Institucional

**Repositório digital complementar ao livro *A Tirania Constitucional: Como a Legalidade Pode Enfraquecer a Democracia*.**

[![Licença: CC BY 4.0](https://img.shields.io/badge/Licen%C3%A7a-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

## O que é este repositório?

Este repositório reúne todos os materiais complementares do Capítulo 9 do livro. O capítulo apresenta uma **proposta metodológica** para o monitoramento da preservação institucional, composta por cinco elementos: o IPI, o SAPED, o registro verificável de eventos, a infraestrutura de transparência e a rede de participação cívica.

> **Importante:** nenhum desses elementos foi implementado. Não há consulta Delphi realizada, dados coletados, análise estatística aplicada ou índice calculado. Este repositório disponibiliza o material conceitual para permitir auditoria futura e colaboração.
