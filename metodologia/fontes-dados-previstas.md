## 3. Tratamento de dados ausentes

- Dados ausentes serão identificados como "não disponíveis";
- A falta de informação não será convertida automaticamente em zero;
- Caso a cobertura seja insuficiente, o resultado será apresentado como incompleto.

## 4. Limitações

- As bases internacionais podem ter cobertura desigual;
- Os dados nacionais podem ter periodicidade irregular;
- A comparabilidade entre países pode ser limitada;
- A qualidade dos dados depende da qualidade das fontes.
