# QR Codes

Este diretório contém os QR Codes do Capítulo 9.

## Arquivos

| Arquivo | Descrição | Destino |
|---------|-----------|---------|
| `qr9-1-repositorio.png` | Repositório do Capítulo 9 | URL do GitHub Pages |
| `qr9-2-documentario.png` | Documentário: A Greve das Mulheres na Polônia | Deutsche Welle |
| `qr9-3-calculadora.png` | Proposta: Calculadora do IPI | `calculadora/calculadora-ipi.html` |

## Como gerar os QR Codes

1. Acesse um gerador de QR Code (ex.: https://www.qr-code-generator.com/);
2. Insira a URL de destino;
3. Baixe a imagem em PNG;
4. Salve neste diretório com o nome indicado.

## Observação

Os QR Codes devem ser gerados após a publicação do repositório no GitHub Pages, para que apontem para a URL correta.
